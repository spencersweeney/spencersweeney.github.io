## Landed Planet Experience

This document describes how the simplified landing experience works, how data flows into the Star Wars–style crawl, and the main levers you can tweak.

### High-Level Flow

1. `src/content.json` defines each planet's narrative copy. Every planet now includes:
   - `crawlIntro`: text shown in the blue intro overlay.
   - `crawlTitle`: the bold crawl headline (e.g., `Episode II – Technical Arsenal`).
   - `crawlText`: paragraph content that fills the crawl body.
2. `src/universe.js` loads texture assets and builds `contentMap`. When you press `E` while looking at a planet in space, the map entry is passed to `PlanetWorld`.
3. `src/apps/landed-planet.js`:
   - Reveals `#content` from `src/index.html`.
   - Draws the animated starfield on `#crawl-stars`.
   - Plays the intro overlay, then hands control to the `CrawlController` to drive the crawl animation (with pause/manual control support).
   - Cleans everything up when you hit `Esc` to return to space.

### Key Files and Elements

- `src/index.html`
  - `#content`: full-screen container that stays hidden until landing.
  - `#crawl-stars`: canvas that renders the star background.
  - `#intro-overlay` / `#intro-text`: blue intro card.
  - `.crawl-container`, `#crawl-title`, `#content-title`, `#content-info`: crawl elements driven by JSON data.
- `src/apps/landed-planet.js`
  - `_PrepareStars()`: sizes the canvas and precomputes stars.
  - `_AnimateStars()`: lightweight RAF loop for the twinkle effect.
  - `_PlayIntroSequence()` and `_StartCrawlAnimation()`: orchestrate the overlay fade and crawl start.

### Tweak Guide

- **Crawl duration**: adjust the controller options in `src/apps/crawl-controller.js` (`duration` & `distance`). Longer durations slow the crawl.
- **Star density**: update the multiplier inside `_CreateStars()` in `landed-planet.js`. The current value `0.4` is tied to `(width + height)`; increase for denser fields.
- **Color/typography**: edit the `.crawl-content` styles in `index.html`. Because the markup is minimal, most presentation changes can happen purely in CSS.
- **Intro timing**: change `introDuration` or `fadeDuration` inside `_PlayIntroSequence()` to keep the blue title card on screen longer or shorter.
- **Copy updates**: modify `src/content.json`. The `crawlTitle` is optional (it hides when omitted), and paragraphs are generated by splitting `crawlText` on blank lines.
- **Contact-only views**: set `layout` to `contact` within a content entry (currently used for the Sun). Provide `contactIntro`, `contactHeading`, and an array of `contactDetails` objects to drive the static Mission Control panel.
- **Clickable links**: plain text URLs (`https://...`) or email addresses inside `crawlText` automatically render as clickable anchors in the crawl; same pattern applies to contact detail values.

### Scroll Controller

- Press `Space` at any time during the crawl to toggle between the automatic cinematic motion and manual control.
- When paused/manual, use your mouse wheel/trackpad or `Arrow Up/Down` (`W/S`) to scroll through the text at your own pace.
- Resuming auto mode (press `Space` again) picks up exactly where you left off so the animation still finishes beyond the vanishing point.
- Customize feel by editing `duration`, `distance`, `wheelScale`, or `manualStep` inside `src/apps/crawl-controller.js`.


### Tips

- Keep JSON text wrapped at reasonable lengths to avoid extremely wide paragraphs in the crawl.
- If you add new planets with fresh textures, import them in `src/universe.js` and add them to the `sources` map so the space scene can display them.
- When experimenting with animations, use the browser dev tools to temporarily set `animation-play-state: paused` on `.crawl-container` to inspect layout mid-crawl.

### Crawl Style Reference (`src/index.html`)

| Selector | Key Properties | What Each Setting Does |
| --- | --- | --- |
| `#content` | `position: fixed` | Pins the overlay so it always covers the viewport regardless of scroll. |
|  | `inset: 0` | Shorthand for `top/right/bottom/left: 0`; stretches to full screen. |
|  | `perspective: 600px` | Defines the depth at which child transforms appear; lower values exaggerate the tilt, higher values flatten it. |
|  | `overflow: hidden` | Keeps the crawl from showing outside the viewport while it animates upward. |
| `#crawl-stars` | `position: absolute; inset: 0` | Makes the starfield canvas match the overlay bounds. |
|  | `pointer-events: none` | Ensures clicks/keys reach the UI underneath (intro overlay/crawl). |
| `#intro-overlay` | `display: flex; align-items/justify-content: center` | Centers the classic blue intro text. |
|  | `transition: opacity 0.8s` | Drives the fade-out when JavaScript adds `fade-out`. |
| `#intro-text` | `max-width: 65%` | Limits line length for cinematic pacing; adjust for more/less wrapping. |
|  | `letter-spacing: 0.2em` | Adds the spaced-out feel of the original films. |
| `.crawl-container` | `transform-origin: 150% 100%` | Sets the vanishing point below/behind the viewer so the crawl recedes into space. Move closer to `50% 100%` for a shallower tilt. |
|  | `animation: crawl 120s linear forwards` | Runs the keyframes once over two minutes; shorten duration for a faster crawl. |
| `.crawl-content` | `position: absolute; left: 50%; transform: translateX(-50%)` | Centers the text column regardless of viewport width. |
|  | `width: 100%` | Allows large text without clipping; constrain if you need a narrower column. |
|  | `font-size: 6.75em` | Controls overall crawl scale. Smaller values shrink everything uniformly. |
|  | `line-height: 2` | Sets spacing between lines; higher values spread text to match the iconic crawl look. |
| `@keyframes crawl` | `rotateX(20deg → 25deg)` | Introduces the perspective tilt; tweak degrees for more/less steepness. |
|  | `translateY(0 → -6000px)` | Moves the crawl upward; larger negative values make the crawl travel farther (important with long scripts). |
|  | `translateZ(0 → -2500px)` | Simulates moving away from the camera; adjust proportional to `rotateX` for consistent perspective. |
| `#crawl-title` | `font-size: 1.2em` (relative to `.crawl-content`) | Elevates the headline slightly above body size. |
|  | `letter-spacing: 0.2em` | Spreads characters to emulate the “EPISODE” treatment in the films. |
| `#content-title` | `color: #f2a900` | Orange tint to separate the planet/section label from the rest of the crawl. |
|  | `text-transform: uppercase` | Keeps naming consistent even if JSON title uses sentence case. |
| `#content-info p` | `font-size: 0.55em` | Keeps paragraphs readable without overwhelming the viewport when stacked vertically. |
|  | `text-align: justify` | Creates dense blocks reminiscent of the movie crawl; switch to `center` for a softer look. |

All crawl visuals stem from these selectors—changing values here (instead of in script) keeps the experience declarative and easy to reason about.
